# Task 9（前端）报告：设置页占位符同义词库

## 变更文件

### `frontend/src/views/SettingsView.vue`
- 新增「占位符同义词」卡片（置于「资料导入配置」与「资产字段配置」之间，`max-width: 720px` 与前两张卡一致）。
- 表格两列：别名（文本输入）→ 规范标签（下拉，选项固定为 `项目名称 / 招标人 / 投标人名称 / 项目编号 / 招标编号 / 标段名称 / 标段编号 / 日期`），行尾「删除」链接按钮，表下「添加一行」，底部「保存同义词」主按钮。
- 说明文案：「别名用于底稿中与规范标签不同的写法（如『采购人』视为『招标人』）；导出与校验共用同一同义词库。」
- 加载：进入页面时 `getPlaceholderSynonyms()`，返回对象转行数组；失败时留空可从零配置。
- 保存：`savePlaceholderSynonyms(mapping)`（全量覆盖）。空别名行忽略；有别名但未选规范标签的行 → 弹出警示并中止保存。保存成功后以服务端返回的规范化结果刷新列表。

### `frontend/src/api/index.js`
- 未改动：`getPlaceholderSynonyms` / `savePlaceholderSynonyms` 已在 Task 8 中添加。

## 设计决策
- 复用设置页既有「映射表格」模式（与人员资质列名/合同业绩列名一致的 small 表格 + 添加一行 + 删除链接），保持视觉与交互一致。
- 规范标签用下拉而非自由输入：后端只认固定标签集合，下拉可避免错别字导致的静默失效。
- 校验策略：空别名静默跳过（常见于用户点了"添加一行"但未填），半填行（有别名无标签）显式拦截——前者是噪声，后者是错误。
