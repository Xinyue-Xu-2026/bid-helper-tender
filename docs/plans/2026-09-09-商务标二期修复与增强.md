# 商务标二期（真实使用反馈批次）实施计划

> 规格来源：用户真实使用反馈 5 条 + exp-1 实证调查。执行方式：逐任务 TDD + 审查，同上一轮。

## 全局约束
- 同前：后端 `backend/` 跑 pytest 全绿、前端 `npm run build` 绿、英文标识符中文文案、每任务 commit。
- 不动既有旧模板导出路径；新行为全部走底稿管线。
- 真实数据只读诊断，测试程序化构造。

## 任务清单

### P1 表格格式保真修复（header_rows 全链路）【修反馈1】
根因实证：人员汇总表两行表头（row0 主表头 + row1 副表头"证书名称/级别/证号/社保页码"），`_fill_table_semantic` 硬编码表头=1 行 → 副表头被删且被当 donor，填入行继承副表头怪异缩进。
- `bid_table_classifier.classify_tables`：触发"跨行表头拼接兜底"时建议项加 `"header_rows": 2`（默认 1）；`bid_draft_service._normalize_binding` 与 `routers/bid_draft.TableBindingIn` 透传 `header_rows`（int, default 1, 1..4 校验）。
- `bid_draft_exporter._fill_table_semantic`：保留前 header_rows 行；donor 取 `rows[header_rows]`（首个真数据行，空白数据行正好携带正确 vAlign/缩进体例）；删除范围 `rows[header_rows:]`；若表头行数 >= 总行数（无数据行）→ donor 用最后一个表头行的克隆但清空文本。
- 简历表值格大缩进不修（原位写入，低优先，记录）。
- 回归：两行表头人员表填充后副表头行保留、数据行体例=原空白数据行；单行表头不受影响。
- commit：`商务标：修复两行表头表格填充保真（header_rows）`

### P2 页码 + 页眉移植【修反馈2+5】
- 页码：导出产物正文页页脚居中 PAGE 域；封面与目录页无页码。实现：底稿为单节时按"封面区/目录区"插分节符拆分节（封面=底稿首个"投标文件"封面页，目录=紧随的目录页），或更简单——`titlePg` + 目录页后分节。技术口径以"除封面与目录页外有页码"为准，实现细节由实现者选最稳方案并写清取舍。
- 页眉：从 `D:\00工作+学习\宏信天德\投标文件\web平台的参考资料（商务标）\商务标.docx` 把页眉**整体移植**（header XML part + 其 rels + media image 逐字节拷贝进产物包，section 加 headerReference 指向它），保证 logo/绿色文本框/宏信天德/深绿粗线 #006400 4pt 完全一致；页脚 PAGE 域与该参考文件一致（居中 9pt）。若底稿原有页眉/页脚则替换为参考样式（一期结论：商务标页眉统一为宏信天德样式，非招标文件样式）。注意封面/目录节不挂该页眉。
- 配置：参考文件路径放 config 常量（如 BID_HEADER_SOURCE_PATH），缺失时降级为不移植（不报错）。
- 回归：程序化构造底稿导出后，断言页脚含 PAGE 域、页眉含图片与指定颜色；封面/目录节无页码。
- commit：`商务标：导出页码与宏信天德页眉移植`

### P3 封面/占位字段填充扩展【修反馈3】
- 招标人名称：底稿裁切时从招标文件前 30 个非空段落规则提取 `^招标人[：:]\s*(\S.+)` → 存底稿行（bid_templates 加字段或塞 bindings）；导出对话框新增"招标人名称"输入框（预填=提取值，可编辑）。
- 投标人名称：导出对话框新增"投标人名称"输入框，默认"宏信天德工程顾问有限公司"（可编辑）。
- 替换规则扩展（compute_text_subs 侧或新增模块函数）：`招标人[：:]\s*[_\s]*$` 类待填标签 → 填值；`投标人名称[：:]` 同理；`（姓名）`/`（投标人名称）` 括号占位在 P5 处理，本任务只处理标签式字段。
- 回归：封面 `招标人：____` → 填值；目录页不受影响。
- commit：`商务标：招标人/投标人名称字段填充`

### P4 法人/代理人资产类型【反馈4 前半】

- settings_store 字段配置若按类型驱动则同步注册。

- commit：`商务标：法人/代理人资产类型`

### P5 授权页填充【反馈4 后半，依赖 P4】
- 导出对话框新增两项选择：法定代表人、委托代理人（下拉自 legal 资产，可空=不填该页）。
- 导出时（底稿管线）：识别底稿中"法定代表人（单位负责人）身份证明"与"授权委托书"页（标题关键词）：
  - 括号占位替换：`（姓名）`→对应姓名（授权委托书中两个"（姓名）"按序=法定代表人/代理人）；`（投标人名称）`→投标人名称；`身份证号：`尾部 → 填对应证件号；"年 月 日"日期位 → 投标文件日期。
  - 身份证扫描件：在"附：…身份证（正反面）电子扫描件"行后插入对应身份证正面+反面图片（法代页=法人正反面；委托书页=双方正反面），宽度沿用现有插图规格。
  - 选择为空 → 该页不动，进填充报告 skipped。
- 填充报告 images/skipped 如实记录。
- 回归：占位替换顺序、身份证双面插入、空缺跳过、防篡改校验不误报（授权页是被写入区域——verify 的段落比对需要把授权页占位替换纳入"允许改动"：compute_text_subs 扩展这些替换规则即可，保持对称）。
- commit：`商务标：法定代表人/委托代理人授权页填充`
